# Media placeholders

Non inserire immagini stock.

Struttura prevista:

- `/media/switch/` — coppia futura di riprese gemelle della sala + poster
- `/media/private/` — foto/video eventi privati
- `/media/nightlife/` — foto/video nightlife e FORMĀ
- `/media/archive/` — flyer e materiale storico

Ogni asset definitivo deve avere:

1. sorgente originale conservata fuori da `public`;
2. poster ottimizzato se video;
3. alt text nel CMS;
4. hotspot/focal point nel CMS quando è un'immagine editoriale;
5. nessun autoplay audio.
